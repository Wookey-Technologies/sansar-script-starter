UIMenu Class

Manages a clickable on-screen menu UI element.

Syntax

[Sansar.Script.Interface]
public class UIMenu : Sansar.Script.InstanceInterface

Remarks

Use this for text-heavy game menus, voting prompts, settings panels, or non-interactive leaderboards.

Show Method

Show a scriptable menu using the default client theme.

Syntax

[Sansar.Script.Interface]
public void Show (string title, string subtitle, string footer, object[] items, float positionXPercent, float positionYPercent, bool interactive, bool closeOnSelection)

Parameters

title
Primary header text.
subtitle
Optional secondary header text.
footer
Optional footer or hint text.
items
List of rows to display.
positionXPercent
Horizontal menu center position in percent of screen width.
positionYPercent
Vertical menu center position in percent of screen height.
interactive
If false, the menu becomes a click-through display panel.
closeOnSelection
If true, the menu closes on the first click.

Returns

The internal event id for the selection completion event.

Remarks

Call this with WaitFor to block until the first menu row is clicked.
